Lesson 3: Model-Context Protocol (MCP)

This module introduces the Model-Context Protocol (MCP), a standardized way to manage and share context between different AI models and agents. MCP is crucial for building coherent and effective multi-agent systems.

Deeper Dive into the MCP Specification

MCP is designed to be a lightweight and flexible protocol. It is typically implemented using JSON or a similar data serialization format. An MCP message usually consists of a header and a body.

  • Header: The header contains metadata about the message, such as the sender, receiver, message ID, and timestamp.
  • Body: The body contains the actual content of the message, which can be a user query, a response from an agent, or any other type of contextual information.

Example of an MCP Message


{
  "header": {
    "sender": "user-123",
    "receiver": "researcher-agent",
    "message_id": "msg-001",
    "timestamp": "2025-08-13T17:00:00Z"
  },
  "body": {
    "type": "query",
    "content": "What is the capital of France?"
  }
}

What is MCP?

MCP provides a structured format for passing contextual information, such as user queries, conversation history, and environmental state, between different components of an AI system. This ensures that all agents have the necessary information to perform their tasks effectively.

Benefits of MCP

  • Interoperability: MCP allows different models and agents, potentially from different developers, to work together seamlessly.
  • Clarity: It provides a clear and unambiguous way to represent context, reducing the risk of misinterpretation.
  • Extensibility: The protocol is designed to be extensible, allowing for the addition of new types of contextual information as needed.

Lab 3: Constructing and Parsing MCP Messages

This lab will guide you through constructing and parsing MCP messages in Python.

1. Constructing an MCP Message

Let's create a Python script to construct an MCP message. Create a new file named `mcp_lab.py`.


import json

def construct_mcp_message(sender, receiver, message_id, content):
    message = {
        "header": {
            "sender": sender,
            "receiver": receiver,
            "message_id": message_id,
            "timestamp": "2025-08-13T17:00:00Z"
        },
        "body": {
            "type": "query",
            "content": content
        }
    }
    return json.dumps(message, indent=2)

# Construct a message
mcp_message = construct_mcp_message("user-123", "researcher-agent", "msg-001", "What is the capital of France?")
print(mcp_message)

2. Parsing an MCP Message

Now, let's add a function to parse an MCP message.


def parse_mcp_message(mcp_message):
    message = json.loads(mcp_message)
    return message["header"], message["body"]

# Parse the message
header, body = parse_mcp_message(mcp_message)
print("\n--- Parsed Message ---")
print(f"Sender: {header['sender']}")
print(f"Receiver: {header['receiver']}")
print(f"Content: {body['content']}")

Add the parsing code to your `mcp_lab.py` file and run it. This lab gives you a practical understanding of how to work with MCP messages, which is a fundamental skill for building multi-agent systems.
