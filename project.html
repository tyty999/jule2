Final Project

In the final project, you will apply everything you've learned in this course to build your own multi-agent system. This is a hands-on project that will challenge you to think creatively and solve a real-world problem.

Project Idea: A Collaborative Research Assistant

Your task is to build a team of AI agents that can collaborate on a research task. The team should consist of the following agents:

  • Researcher Agent: This agent is responsible for searching the web for information on a given topic.
  • Writer Agent: This agent takes the information gathered by the Researcher Agent and writes a summary.
  • Editor Agent: This agent reviews the summary written by the Writer Agent and suggests improvements.

Requirements

Your multi-agent system must meet the following requirements:

  • Agents must communicate with each other using an A2A protocol.
  • Context must be shared between agents using MCP.
  • The system must be built using the ADK SDK.

Submission

You will need to submit your source code, a demo of your project, and a short report explaining your design choices.
