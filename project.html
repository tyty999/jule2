Final Project: Building a Collaborative Research Assistant

In the final project, you will apply everything you've learned in this course to build your own multi-agent system. This is a hands-on project that will challenge you to think creatively and solve a real-world problem. You will be building on the concepts and skills you developed in the previous labs.

Project Idea: A Collaborative Research Assistant

Your task is to build a team of AI agents that can collaborate on a research task. The team should consist of the following agents:

  • Researcher Agent: This agent is responsible for searching the web for information on a given topic. You will need to integrate this agent with a search API.
  • Writer Agent: This agent takes the information gathered by the Researcher Agent and writes a summary. This agent should be able to synthesize information from multiple sources.
  • Editor Agent: This agent reviews the summary written by the Writer Agent and suggests improvements. This could involve checking for grammar, style, and factual accuracy.

Revised Requirements

Your multi-agent system must meet the following requirements:

  • A2A Communication: Agents must communicate with each other using a robust A2A protocol. You can implement your own message bus, as we did in Lab 4, or use a more advanced library.
  • MCP for Context Sharing: All communication between agents must use the Model-Context Protocol (MCP). You will need to design your own MCP message formats for the different types of interactions.
  • ADK SDK: The entire system must be built using the ADK SDK. This will help you manage the complexity of the project and ensure that your agents are well-structured and maintainable.
  • Code Quality: Your code should be well-documented and follow best practices.

Submission

You will need to submit the following:

  • The complete source code for your project.
  • A `README.md` file with instructions on how to run your project.
  • A short video demonstrating your project in action.
  • A report (2-3 pages) explaining your design choices, the challenges you faced, and what you learned.
