Welcome to the Course!

This course provides a comprehensive introduction to modern generative AI agents development. You will learn about multi-agent systems, Model-Context Protocol (MCP), Agent-to-Agent (A2A) communication, and how to use the ADK SDK from Google to build your own agents.

This course is designed for students with intermediate Python skills. No prior experience with AI or machine learning is required, but a willingness to learn and experiment is essential.
